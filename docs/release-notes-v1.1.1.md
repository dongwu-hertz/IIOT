# HAIS v1.1.1 Release

发布日期 / Release date: 2026-11-24

## Language changes

- Language picker order is now English → 简体中文 → 繁體中文 → Español → Türkçe → Русский.
- English is the product fallback language when no saved or OS-detected language is available.
- Windows installer language selector now includes Traditional Chinese (`zh_TW`) and orders English, Simplified Chinese, Traditional Chinese first.
