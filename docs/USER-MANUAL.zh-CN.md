## 第 1 章 产品简介

### 1.1 软件定位

HAIS（原 HERTZINNO Acoustic Box Manager）是一款面向工业现场声学监测场景的 **Windows 桌面管理软件**，以 **局域网（LAN）管理** 为核心：电脑与设备接入同一局域网后，即可集中完成设备接入、实时监测、告警处置、录音回放、历史趋势分析与 GIS 点位管理。软件为离线优先设计，数据保存在本机，不依赖公网服务器。

### 1.2 主要功能一览

| 功能 | 说明 | 详见 |
|---|---|---|
| 设备管理 | 自动识别机型、批量管理多台设备、参数配置、固件升级、维护 | 第 8 章 |
| 实时监测 | 多路视频墙（1/4/9/16 分屏，同机多视图同屏、满屏自动轮询）、实时特征/频谱/时频图、音频监听 | 第 6、9 章 |
| 告警与事件 | 声纹设备告警中心 + 四路来源合并的事件中心（处置工作流） | 第 10、11 章 |
| 录音与回放 | 告警/手动/定时录音的列表、播放、下载 | 第 12 章 |
| 样本库 | 异常声纹样本、人工标注、本机训练评估、数据集导出、AI 辅助标注 | 第 13 章 |
| 历史趋势 | 多通道多指标长期趋势查询、缩放、导出 CSV、打印为 PDF | 第 14 章 |
| GIS 地图 | 设备落点图、离线点位图、可选在线底图、实时数据工作台 | 第 7 章 |
| 告警联动 | 设备告警触发本机录像 / 弹窗 / 提示 / 邮件四路动作（默认关闭） | 第 15 章 |
| 多语言 | 简体中文 / English / Español / Türkçe | 第 15 章 |

### 1.3 四类设备简介

| 设备类型 | 典型型号 | 说明 | 主要能力 |
|---|---|---|---|
| 声纹设备 | AE08 / FA8 系列 | 多通道声纹采集盒（8 通道，实测采样率 96 kHz） | 实时特征、频谱、时频图、音频监听与录音、告警、8 页签完整配置 |
| 声学相机 | FA371 | 声源定位成像相机，视频经 RTSP 取流 | 实时视频、五路声学数据（声纹图/音频/频谱/能量点/检测反馈）、检测启停、告警策略、检测记录下载 |
| 听诊盒子 | E2 / FA100 / FA110 | 设备状态声学监测盒（2023 版协议） | 参数读取与修改、告警同步（含录音与时频谱图下载）、本机录音回放 |
| 空气声呐 | SN-16 | 声源定位声呐，可联动球机（PTZ）抓拍 | PTZ 联动配置、告警 + 球机抓图（最多 3 张）、每秒实时值回调、点位图 |

> 添加设备时**不需要选择机型**：软件按地址自动识别协议（声纹设备 / 听诊盒子·空气声呐 / 声学相机），识别结果显示在「测试连接」之后。空气声呐与听诊盒子属同一家族，软件按设备返回的参数自动区分代次。

### 1.4 运行环境

- **操作系统**：Windows 10 / 11（64 位）。
- **网络要求**：电脑与设备处于**同一局域网**，能直接访问设备的 IP 地址。
- **磁盘要求**：软件会把录音、录像、抓图、趋势数据写入本机存储目录（默认 `D:\HertzinnoData`，可在设置中修改）。多通道高采样率录音占用空间很大，请为大容量磁盘预留空间，**切勿放在系统盘**。
- **显示**：推荐分辨率 1440×900 及以上。

## 第 2 章 安装与卸载

### 2.1 获取安装包

安装包文件名为 `HAIS-<版本>-<发布日期>-x64-setup.exe`（例如 `HAIS-1.0.19-2026-09-21-x64-setup.exe`），由 HERTZINNO 随设备交付，也可联系厂家支持获取。安装包体积约 127 MB（内置视频转封装组件）。

### 2.2 安装步骤

1. 双击安装包。安装向导首先提示**选择安装向导语言**：简体中文 / English / Español / Türkçe，按需选择后进入安装。
2. 按向导提示选择安装目录，点击「安装」直至完成。
3. 首次运行若出现 Windows SmartScreen 提示「Windows 已保护你的电脑」：本软件安装包未做代码签名，点击 **「更多信息」→「仍要运行」** 即可继续。

> 安装向导语言只影响安装过程；软件界面语言可在「系统设置 → 常规（语言）」中随时切换（见 15.1）。

### 2.3 首次启动

1. 启动软件后先显示**登录界面**。
2. 使用出厂账户登录（详见第 4 章）。首次登录会**强制要求修改密码**，按提示设置新密码后自动进入主界面。

### 2.4 卸载

打开 Windows「设置 → 应用 → 已安装的应用」，找到 **HAIS**，点击「卸载」并按提示操作。卸载不会删除存储目录中的录音、录像等数据文件；如确需清除，请手动删除存储根目录（卸载前请在「系统设置 → 常规（存储）」中确认存储路径）。

## 第 3 章 快速开始

按下面五步操作，约 10 分钟即可完成从登录到实时监测的全过程。

1. **登录并修改密码**
   启动软件 → 输入用户名 `admin`、出厂密码 `Hz@123456` → 点击「登录」→ 按提示修改密码。

2. **确认存储路径（建议）**
   点击左侧导航「系统设置」→「常规（存储）」→ 确认「存储路径」指向大容量磁盘 → 需要更改时点击「浏览…」选择新目录并保存。

3. **添加设备**
   点击左侧导航「设备管理」→ 点击顶栏右侧「添加设备」→ 在对话框中填写：
   - 设备 IP 地址（必填）；
   - HTTP 端口（设备默认 80）；
   - 用户名、密码（设备出厂账户，详见设备随附资料）。
   点击「测试连接」→ 等待出现「已识别为：…」与固件版本信息 → 点击「添加」。

4. **打开实时监测**
   点击左侧导航「实时监测」→ 在顶栏设备下拉框中选择刚添加的设备（选中后自动开始接收数据，无需再点开始按钮）→ 切换通道页签 CH1–CH8 查看各通道的实时趋势、频谱、时频图。

5. **查看相机画面（如有声学相机）**
   声学相机添加成功后，打开「总览」页，视频墙会在进入页面时自动播放相机画面；也可以在「实时监测」页选中相机查看 16:9 实时视频。

后续章节将详细介绍每个页面的用法。

## 第 4 章 账户与登录

### 4.1 登录界面

- **用户名 / 密码**：输入账户信息后点击「登录（Sign In）」。
- **记住密码（Remember Password）**：勾选后本机记住凭据，下次自动填入；记住的密码超过 90 天需重新输入。用户名始终会记住。若本机系统加密不可用，勾选框将被禁用并提示。
- **忘记密码？（Forgot password?）**：见 4.4 超级密码找回。

**安全机制**：同一用户名连续 **5 次**登录失败，账户锁定 **60 秒**，锁定期间即使密码正确也拒绝登录。

### 4.2 出厂账户与首次登录

| 项目 | 内容 |
|---|---|
| 出厂用户名 | `admin` |
| 出厂密码 | `Hz@123456` |

首次登录必须修改密码（出厂密码印在文档中，继续使用等于没有门禁）。新密码要求：**至少 8 位；不能包含用户名；首尾不能有空格**。

### 4.3 管理员与普通用户

| 能力 | 管理员（admin） | 普通用户（operator） |

| 总览 / 地图 / 实时监测 / 告警 / 事件 / 录音 / 趋势 / 样本库查看 | ✅ | ✅ |

普通用户登录后，上述写入类按钮被禁用或隐藏。除角色这一粗分外，软件还支持**按项权限**（如「设备配置写入」「下载检测记录」等 12 项），管理员可在创建账户时逐项勾选，界面上每一项权限都写明了它管住哪些操作。

### 4.4 忘记密码：厂家超级密码找回

本软件密码无法自行找回，需由厂家签发**每台电脑不同的超级密码**：

1. 在登录页点击「忘记密码？」。
2. 页面上显示本机**安装标识**（由本机首次启动生成，每台电脑不同；它是标识符、不是秘密）。点击「复制」抄下安装标识。
3. 联系 HERTZINNO 技术支持（info@hertzinno.com），提供安装标识，获取一串 **16 位超级密码**。
4. 在找回页面粘贴/输入超级密码 → 选择要重置的账户 → 输入新密码 → 点击「重置密码」→ 用新密码登录。

> 超级密码只能**重置已存在账户的密码**，不能登录、不能新建账户、不能改角色。找回后原账户的强制改密状态按重置结果处理。

### 4.5 修改密码与退出登录

- **修改密码**：侧栏底部账户菜单 →「修改密码」，或「系统设置 → 账号 → 当前会话 → 修改密码」。需输入当前密码与新密码（两次一致）。
- **退出登录**：侧栏底部账户菜单 →「退出登录」，或「系统设置 → 账号 → 当前会话 → 退出登录」。退出后回到登录界面；未登录时软件不会加载任何设备数据。

> 软件账户与设备账户是**两套独立体系**：AE08 声纹设备与 FA371 相机的设备账号（admin）由设备固件管理，本软件的账户密码不影响设备凭据；添加设备时填写的设备凭据保存在操作系统凭据库中，加密存储、不回显。

## 第 6 章 总览

「总览」是打开软件后的默认页面，核心是一面**实时视频墙**：把多台相机、以及同一台相机的视频与声学图表同屏铺满，一眼掌握全场态势。

### 6.1 实时视频墙

- **分屏档位**：1 / 4 / 9 / 16 分屏，档位控件在视频墙右上角。每一格放一个「内容」：一台相机的实时视频流，或一种声学图表。
- **一格一种内容，同机可多格**：同一台相机可以同时占用多个窗口，每个窗口显示一种内容——**视频流 / 1 秒时域图 / 频域图 / 时频谱图**。**相同内容（同一相机 + 同一视图）全墙只允许出现一次**，已上墙的组合在选择器中标出「已在窗口」并禁用；同一相机的不同视图可同屏共存。在格子上把内容从「播放」切成图表会自动释放该相机的视频会话，切回视频时自动重连。
- **添加内容（两步）**：点击空格正中的「+」（或点击已有格叠加条上的设备名重新选择）→ 第一步在清单中选择**相机** → 第二步选择**内容类型**。第三方手填 RTSP 源只有「播放」一种内容，选中即放入。
- **自动播放**：进入总览页时，已选中的相机会自动开始播放（可在「系统设置 → 常规（视频与缓冲）」关闭）。
- **窗口放满后自动轮询**：所有窗口都有内容时再添加，新内容进入**轮询队列**；每 10 秒自动轮换一格，被换下的内容排到队尾、周而复始。工具条出现轮询指示器「轮询 在屏数/总数」，可**暂停 / 继续**；手动清空某一格会把该内容移出轮询；正在出声的那一格被轮走时自动静音。
- **单格控制**：每格上方的叠加条（设备名 / 状态 / 码流信息）**常驻显示**；每格底部为播放器控制条——告警配置 / 全屏 / 暂停 / 切换录像 / 音量 / 手动录像；右键画面格弹出更多操作（见 9.2）。一台相机在别的页面播放时，本页对应格会提示「画面在另一个页面上」，点击即可接管。
- **音量**：点击控制条上的音量图标，在其正上方弹出水平细滑条卡片（约为格宽的 20%），左右拖动调节；调节的同时这一格成为全场唯一出声格，浮层内另有声音开关。
- **手动录像**：控制条上开始 / 停止录像。录像失败时提示具体原因——「录像文件为空（0 字节）」请检查磁盘空间与相机码流后重试；「录像文件不完整（缺少 moov 索引）」说明视频流在录制过程中中断——并附诊断信息，不再是笼统的「存储失败」。
- **图表样式**：频域图与时频谱图在设备上报采样率时显示**真实频率轴**（kHz 刻度，频率上限封顶 100 kHz）；采样率未知时横轴按「谱线序号」显示，不编造刻度。时频谱图采用红外热力色板，三种图表整体为暗底科学仪器风格（细轴线、坐标刻度）。**颜色只表示同一帧内谱线的相对强弱，不代表绝对声压级**。
- **同时直播上限**：默认 4 路（可在「系统设置 → 常规（视频与缓冲）→ 同时直播路数上限」调整）。超出上限时画面格会写明原因，需先停止其他格。
- **第三方相机**：手填 RTSP 源只有画面、无声学数据视图。按产品要求，新增与管理入口已下线；本次运行内已添加的源仍可在格子选择器第一步中选用，地址不落盘，重启软件后不再保留。

### 8.1 设备表

打开「设备管理」，设备以表格列出，共十列：

**序号 / 设备名称 / IP 地址 / 设备类型 / 状态 / 告警数量 / 通道数 / 查看 / 设置 / 删除**

| 打开设备 Web 界面 | **双击**该行的 IP 地址（在系统浏览器中打开设备自带网页） |
| 查看（眼睛图标） | 跳到「实时监测」并选中该设备 |
| 设置（齿轮图标） | 打开编辑设备对话框（名称 / 端口 / 凭据 / 地址信息） |
| 删除（垃圾桶图标） | 删除设备（弹确认框） |

> 单击行仅选中不高亮跳转。状态列显示 在线 / 离线 / 未知；「告警数量」为该设备在本机的告警记录条数。

### 8.2 添加设备

1. 点击顶栏右侧「**添加设备**」→ 先选择**接入方式**：
   - **IP 地址**（默认）：软件主动连接设备。填写 **IP 地址、HTTP 端口（默认 80）、用户名、密码**；「**更多（GIS）信息**」折叠块（默认收起）为声源定位设备（SN-16 空气声呐）录入经纬度（WGS84 十进制度）与方位角（0 = 正北，顺时针；360 请写 0），其他机型可留空。
   - **HTTP / MQTT**：设备主动向本机推送数据（ThingsBoard 式接入），用于接入第三方推送设备。填写**设备名称**（必填）；「GIS 信息」默认展开；**数据流接口键**（声压级 / 主频 / 平稳度 / 频带能量比四个遥测键，默认规范键名，设备用别的写法时才需要改）与**视频流接口键**（哪一个键装视频地址，留空 = 这台设备不推视频）。
2. 对话框下方的「**本机接入**」显示监听地址 / 端口、监听状态与收数统计（按设备声明自动开关，此处只查看与保存监听设置）。
3. **IP 地址**模式点击「**测试连接**」：自动识别机型并显示「已识别为：…」、往返延迟、认证方式、固件版本；提示「设备无响应」请核对 IP / 端口 / 型号，提示「认证失败」请核对用户名密码。**HTTP / MQTT** 模式无测试连接，保存即创建。
4. 点击「添加」。已注册设备不会重复建条目（IP 模式只更新连接地址）。
5. HTTP / MQTT 添加成功后，对话框显示本机**推流地址与秘钥**：HTTP 推流 URL 形如 `http://<本机IP>:<端口>/api/v1/<秘钥>/telemetry`；MQTT 目标 `mqtt://<本机IP>:<端口>`、主题 `v1/devices/me/telemetry`、**秘钥即 MQTT 用户名**。点击「复制」填到设备侧推送配置中。秘钥可按设备轮换，轮换后旧秘钥立即失效。

### 8.3 设备详情与配置

点击设备名称**在当前页面弹出设备详情弹窗**（不再跳页；设备管理、地图页、告警中心、事件中心的设备入口均如此）。弹窗标题一行显示**设备名 + 设备 ID + MAC**，右侧为状态徽标与当前采样率，并有「打开设备页面」（设备自带 Web 界面）、「监测」（跳实时监测）按钮；下方页签**按机型显示**：

| 机型 | 页签 |
|---|---|
| 声纹设备（AE08/FA8） | 概览 / 通道与采样率 / 告警参数 / 网络配置 / 时间·NTP / RS485·Modbus / Push 上报 / 设备维护 |
| 声学相机（FA371） | 概览 / 检测模式 / 告警策略 / 维护与升级 |
| 听诊盒子（E2/FA100/FA110） | 概览 / 听诊盒子 / 设备维护 |
| 空气声呐（SN-16） | PTZ 联动 |
| 推送设备（HTTP / MQTT 接入的第三方设备） | 概览 / 推送 |

> **推送设备**没有 IP 轮询：收到设备推送的遥测即上线，超过阈值时间没有收到遥测判离线。它的「概览」页签装基础信息与地址信息，「推送」页签装本机推流地址与秘钥（可复制、可轮换）；**通过 IP 添加的设备不显示推流秘钥**（推流端点只在推送设备上显示）。

- **概览**：IP、HTTP 端口、MAC、固件版本、FPGA 版本、Web 版本、通道数量、采样率、最近在线时间；可修改**设备名称**（写进设备并读回核对）、查看/复制**地址信息**（「在地图信息里查看」直接跳到地图页并选中该设备）。
- **通道与采样率**（声纹设备）：通道表（名称、传感器类型 麦克风/骨传导、启用开关、绑定告警配置）、采样率修改。**修改采样率会使设备重启采集**，正在进行的实时监测会中断，需确认后应用。
- **告警参数**（声纹设备）：告警配置列表（名称、检测模式 特征检测/AI 检测、检测灵敏度、干扰抑制等级、已启用判据）。支持新增 / 编辑 / 删除配置；声压级（过载/突升/突降/稳定性阈值）、主频（上下限）、频带能量比（上下限与阈值）按判据填写。删除前需先在通道配置中解除绑定，否则设备会拒绝删除。
- **网络配置**：手动 / DHCP；修改 IP、掩码、网关、DNS 与端口。**保存会立即断开当前连接**：软件自动按新地址重连并核对，最长约 45 秒；新地址无响应时自动回退原配置；新旧地址都不通时，只能通过设备本地界面或串口恢复。
- **时间 / NTP**：查看设备时间与本机时间偏差、「立即对时」、启用 NTP 并填写服务器（如 cn.pool.ntp.org）与同步间隔。
- **RS485 / Modbus**：工作模式、串口（左/右）、波特率、数据位、停止位、设备地址；Modbus 类型、端口、从站地址（1–247）。单位以设备为准。
- **Push 上报**：读取设备四路推送通道（特征/告警/图形/热力）的目标地址。**若目标包含公网地址，页面会醒目警告**「设备正在向公网地址上传数据」——如不希望数据外发，请在设备本地界面关闭对应通道或改为内网地址。
- **设备维护**（破坏性操作，均带二次确认）：重启设备；系统升级；恢复出厂设置（需输入 `RESET` 确认，设备上全部配置恢复出厂值）；固件上传（选择固件文件，上传后设备自动升级并重启）。
- **PTZ 联动**（空气声呐唯一页签）：启用球机联动、球机 IP/端口/账号/口令（口令不回显，留空 = 不修改）、球机方向与声呐一致、告警时保存抓图、实时监听通道；「保存到设备」后逐项**读回核对**（显示「生效 / 未生效：应为…设备现为…」）；「与球机对时」向设备发送对时请求并显示设备是否接受。
- **检测模式**（相机）：运行模式（单次检测 / 智能巡航）与应用模式（局部放电 / 气体泄漏 / 机械异响）分开设置，写入后均重新读取核对；切换应用模式会弹确认框提示风险。
- **告警策略**（相机）：告警策略与告警条件两个页签，读取/新建/编辑/删除设备侧策略与条件（dB 判据、主频判据、频谱比对、放电判据、检测周期、灵敏度等）。**设备同一时间只允许启用一条策略**；「开始检测」前必须先启用一条策略。
- **维护与升级**（相机）：固件版本 / SDK 版本 / Web 界面版本 / 上次升级时间；「打开相机 Web 界面」；固件升级（选择升级包 → 显示大小与 SHA-256，请与厂家发布的校验值核对 → 上传 → 重启设备开始升级，升级期间勿断电断网）。「版本回滚 / 恢复出厂」因设备开放接口未提供该操作而禁用（悬停可见原因）。

> **未保存修改**：在配置页签（告警参数 / 网络配置 / 时间·NTP / RS485·Modbus / Push 上报等）有未保存修改时切换页签或关闭弹窗，会弹出确认「当前页签有未保存的修改，继续将丢失这些修改」——选择「放弃修改」或「继续编辑」。

> 设备凭据保存在本机操作系统凭据库中（加密），界面不回显；编辑设备时用户名/密码**留空 = 不修改**。

### 8.4 编辑与删除设备

- **编辑**（设备表「设置」列）：修改显示名称、HTTP 端口、用户名/密码（留空不改）、地址信息。**IP 地址不可修改**（IP 决定设备身份）；相机因设备无身份接口，身份由地址铸造——相机改 IP 需按新地址重新添加，会被视为新设备。
- **删除**（设备表「删除」列）：弹出确认框。删除后该设备的**历史告警与录音记录保留**，但本地保存的连接凭据被清除。

**左列（约 65%）**

- **实时视频**：16:9 视频窗口随列宽撑满，选中相机即自动播放（相机侧需已启用 RTSP，未启用时页面会提示去相机 Web 界面「高级设置 → RTSP」开启）。卡片无标题、无状态徽标行，正在录像的红点保留。视频上方的信息叠加条默认显示，可用控制条上的「**叠加**」按钮切换显隐（总览页视频墙的叠加条仍常驻）。
- **视频控制条**：**告警配置 / 全屏 / 暂停 / 切换录像 / 红外 / 叠加 / 音量 / 手动录像**。音量点击弹出浮层（滑杆 + 静音开关，音量值按设备记忆）；「**红外**」浮层显示中心温度 / 最高温度 / 最低温度 / 发射率——设备仅提供温度数值、暂无红外视频流，浮层会如实说明；「**叠加**」切换视频上信息条的显隐。
- **检测结果**：检测文本列表；「**检测记录库**」按钮打开检测记录下载对话框。
- **告警信息**：该相机最近告警列表 + 「查看告警中心」链接。
- **声学波形**：实时音频波形，保留播放能力（可开声音）。

**右列（约 35%，纵向）**

- **相机控制**：检测模式（单次检测 / 智能巡航）、应用场景（局部放电 / 气体泄漏 / 机械异响三档成像预设，显示当前频带 / 目标数量 / 成像阈值，应用后读回核对、可「还原」）、检测启停（开始检测前需先在设备详情启用一条告警策略）。
- **告警配置入口**：打开相机告警配置对话框（策略与条件，见 8.3）。
- **声纹图**：设备推送的声纹图像（JPEG）。
- **频谱图**：频谱曲线（设备未上报采样率时横轴按谱线序号标注）。

**画面右键菜单**：抓图 / 录像（手动录像、停止录像、抓图）· **画面翻转**（左右翻转 / 上下翻转 / 旋转 90°，带勾选态——三个翻转开关已从控制条移入本菜单）· 全屏 · 复制 RTSP 地址（含设备口令，可复制为打码版本；剪贴板写入权限已内置放行）· 在外部播放器打开 · 回放本机录像 · 下载检测记录。不可用的菜单项会灰显并**写明原因**；总览页视频墙的右键菜单不受影响。

> **会话管理**：进入相机分支时自动建立声学数据会话（声纹图 / 音频 / 频谱 / 能量 / 检测反馈五路 + 红外数据；管理员账户自动开始接收，普通账户需管理员先建立会话），离开页面自动释放，无需手动开关。能量数据通道仍在后台订阅，但能量点表格已下线，本页不再显示。

### 9.3 听诊盒子（E2/FA100/FA110）

- **设备状态面板**：协议代次（听诊盒子 2023 版 / SN-16 空气声呐 V3.2 协议）、工作模式（突发大声音 / 旋转类设备 / 电力设备状态监测；空气声呐无工作模式）、采样率、通道数、时频谱图尺寸、设备型号、固件版本、告警记录上限（设备只保留最近 5000 条）。
- **参数表**：设备全部运行参数按组显示（阈值 / 相机 / 开关 / 其它），认不出的键按原键名显示。
- **同步告警**：把设备上的告警日志与录音拉到本机。可勾选「同时下载时频谱图 / PTZ 抓图」。结果显示：检查 N 条（新增 / 已在库）、录音（新下载 / 已有 / 失败）、时频谱图与抓图张数、时间无法解析跳过的条数。重复同步不会重复入库。
- **本机录音回放**：直接回放已同步到本机的告警录音。
- **时间轴回放**：本分支保留独立的时间轴回放（未并入趋势卡）。

> 这一代设备目前**没有接入实时音频/时频流**，本页如实只提供参数、告警同步与本机回放。

### 9.4 空气声呐（SN-16）

在 9.3 的听诊盒子面板基础上，空气声呐还提供：

- **安装点位卡片**：只读显示录入的经纬度 / 方位角。
- **SN-16 实时值回调**：点击「在本机接收」，软件把本机地址写入设备的 `notify_url`（写入后逐项读回核对）。开启后设备每秒上报最大声压级 / 最大通道 / 时域能量比 / 频域能量比，地图页工作台与设备卡片实时刷新；「停止接收」后设备停止上报。此写入操作需要管理员。
- 设备详情页提供「PTZ 联动」页签（见 8.3）。告警抓图在地图页「同步告警」后查看（最多 3 张）。

### 9.5 第三方相机（手填 RTSP）

按产品要求，实时监测页**已不再提供**第三方相机（手填 RTSP）的新增与管理入口。本次运行内此前已添加的源仍可在「总览」页视频墙的格子选择器中选用播放（此类源只有画面、无声学数据视图）；地址不落盘，重启软件后不再保留。

## 第 10 章 告警中心

「告警中心」（/alarms）管理**声纹设备（含听诊盒子 / 空气声呐）本机告警记录**；相机检测事件请在「事件中心」查看（第 11 章）。

### 10.1 筛选与列表

- **筛选表单**：字段式表单，一行一项、每项占筛选区约半宽（窗口窄时占整行），共五项——**设备**（下拉）、**告警类型**（下拉）、**时间范围**（日历组件：点按钮弹出，快捷档 全部 / 今天 / 最近 1 小时 / 最近 24 小时 / 最近 7 天 + 月历点选起止日期与起止时刻）、**标题**（按设备名模糊搜索）、**内容**（按备注 / 设备告警原因文本模糊搜索）。
- **操作行**（筛选表单最底一行，按钮同排）：**重置**（清空筛选）/ **批量确认** / **取消确认** / **加入样本库**（后三项需先勾选列表行）。从设备详情弹窗带设备筛选过来时，列表已按该设备过滤（筛选行不显示额外条件）。
- 列表按时间倒序分页显示：时间 / 设备 / 通道 / 告警类型 / 等级 / 状态。
- 告警类型包括：声压级异常、主频异常、频带能量比异常、平滑度异常、夹具松动、冷却器异常 A/B、过载、短路冲击、沿面放电、电晕放电、间隙放电、悬浮放电、直流偏磁等（听诊盒子 / 空气声呐的告警以设备自己上报的原因为准）。
- 勾选多条后可**批量确认 / 取消确认**，或「加入样本库」（见第 13 章）。

### 10.2 告警详情

**点击一条告警**打开详情抽屉：

- **告警时刻指标**：该告警触发时的声压级 / 主频 / 平稳度 / 频带能量比等读数。
- **录音回放**：有本地录音文件可直接播放；没有时可前往「录音文件」页处理。
- **告警视频**：该告警的录音是 MP4 容器时，显示视频回放。
- **告警抓图**：听诊盒子 / 空气声呐每次告警的球机抓图（最多 3 张）。
- **确认 / 取消确认**：改变告警的确认状态。
- **告警等级 / 备注**：为告警选择等级、填写备注（有长度上限）并保存。
- **样本库**：把该告警的指标与弱标签存入样本库（已在库中不会重复写入）。
- **上一条 / 下一条**：在当前筛选结果内逐条查看。

**右键任意一行**弹出快捷菜单：

| 菜单项 | 作用 |
|---|---|
| 查看详情 | 打开详情抽屉 |
| 回放 | 打开详情并自动播放录音 |
| 下载告警 | 把本机录音**另存为**到自选位置；没有本机录音的条目禁用并注明「这条告警没有本机录音，无法下载」 |
| 加入样本 | 该告警加入样本库 |
| 确认 / 取消确认 | 切换确认状态 |

## 第 11 章 事件中心

「事件中心」把**四路来源**按时间倒序合并成一条时间线，是现场处置异常的主工作台：

| 来源 | 内容 | 能否在本机确认 |
|---|---|---|
| 相机检测日志 | FA371 每次检测的记录与结果文件 | 不能（设备开放接口无确认能力，界面如实标注） |
| 本机告警联动 | 设备告警触发的本机动作记录（录像/弹窗/提示/邮件） | 可以 |
| 声纹设备告警 | 声纹设备 / 听诊盒子 / 空气声呐的本机告警 | 可以 |
| 设备状态 | 设备每次**上线 / 离线**状态翻转各产生一条事件（离线 = 警告、上线 = 提示） | 可以 |

> 设备状态事件从软件升级后开始记录（升级前的状态历史没有留存）；可在筛选卡的「来源」下拉按该来源筛选。

### 11.1 队列与筛选

- **筛选卡**：字段式表单，一行一项、每项占筛选卡约半宽（窗口窄时占整行）——**时间范围**（与告警中心同一个日历组件：快捷档 全部 / 今天 / 最近 1 小时 / 最近 24 小时 / 最近 7 天 + 月历点选起止日期与时刻）、**来源**（相机检测日志 / 本机告警联动 / 声纹设备告警 / 设备状态）、**事件类型**（严重等级，只列当前数据里真实出现的档）、**状态**（全部 / 已确认 / 未确认）。最底一行为**重置**；勾选了行时同排出现「确认所选」。
- **行内展开**：点击队列行内的**时间**（或展开钮）就地展开三行摘要——**事件名称、对应设备、该设备当前状态**（在线 / 离线徽标）；再点一次收起。
- 队列每行左侧为 3 px 严重度色条；键盘 ↑ / ↓ 移动选中，Enter 打开抽屉。相机日志的设备时间戳按秒解读，可能标注「近似时间」；设备没给时间的按读取时刻排序并在「来源读况」中说明各源读取/截断情况。
- 任一来源读取失败不影响其他来源。

### 11.2 事件详情抽屉

点击队列行打开右侧抽屉（宽 400–560 可拖拽，Esc 关闭，↑/↓ 或 J/K 换条），共五个页签：

- **概览**：状态、首次探测 / 最后探测、持续时长、次数，以及事件属性网格（事件标识、设备、来源、设备原始时间戳、检测日志编号、指标等）。
- **证据**：图片证据（联动抓帧 / 球机抓图，无图时说明具体原因）、录音录像（本机录像播放）、指标、检测结果文件（每个文件一个下载按钮，下载后登记为录像、可重复下载不覆盖；下载需要管理员）。
- **时间线**：首次探测 + 各次触发节点 + 本机联动动作，按时间排列。
- **关联**：同设备 / 同一种事件 / 前后 10 分钟三组相关事件（在已加载范围内查找），点击直接跳到那一条；**Incident 关联**（见 11.3）。
- **活动**：处置记录流水（谁在何时做了什么）。

### 11.3 处置工作流与 Incident

- **状态机**：待处理 → 已确认 → 调查中 → 已解决 → 已关闭；另有 已静默 / 重新开启。抽屉头部按当前状态给出一个主按钮（如「确认」「开始调查」「标记已解决」）与若干次要动作（静默 / 关闭 / 重新开启（必填原因）/ 指派给某账户）。处置动作**需要管理员账户**；确认动作会同时写入来源侧（相机检测日志无确认接口，故不能确认）。
- **Incident 关联**：把多条告警关联成一个现实问题（Incident）。当同设备上达到建议阈值（默认 2 条，可在建议卡旁调为 3 / 5 / 10）时出现「可能相关的 Incident」建议卡；可「创建 Incident」（填写标题，如「1 号风机异常情况」，可附备注）或「关联到已有 Incident」。一条告警可同时属于多个 Incident；「解除关联」随时可用。Incident 只建关联，不自动关闭或合并任何告警。

## 第 13 章 样本库

「样本库」保存**异常声纹样本**，用于积累训练数据：可从告警记录或录音文件一键入库，也可导入。

### 13.1 样本与标签

- 顶部统计：样本总数 / 可参与训练 / 故障：人工 / 设备：人工 / 故障：设备判定 / 故障：AI 建议 / 设备类型未标。
- 每个样本带两个标签维度：**设备类型** 与 **故障类型**；标签来源三档权重不同：人工标注（真值）＞ 设备判定（弱标签）＞ AI 建议（候选，不覆盖人工、不进训练集）。
- **标签库**：两栏（设备类型 / 故障类型），可直接选用已有写法，也可输入新名字（自动入库）；标签支持改名（同步更新所有样本）与删除（仍有样本在使用时不允许删除）。
- 每行可「改标签」或撤销标注；可删除样本。样本的「特征」列显示设备上报过的特征维度（缺维度不补 0）。

### 13.2 训练评估、AI 标注与导出

- **训练并评估（Train）**：使用本机算法对**带人工标签且特征齐全**的样本做留一法评估，结果包括参与训练数、留一法准确率、被排除原因、训练集设备类型分布、混淆矩阵。只有一个类别时准确率恒为 100%（界面会说明此数无信息量）；混设备的训练集会给出提示。
- **AI 标注（可选）**：AI 服务在「系统设置 → 集成（AI 服务）」中配置（可保存多条命名服务，选中哪条用哪条）；样本页的 AI 面板负责管理**当前启用**的那条服务（启用开关、接口地址、模型、密钥）并运行标注。密钥经系统加密保存、界面不回显。让 AI 标注后，它为未标注样本给出**候选标签**；AI 建议不会覆盖人工标注、也不进入训练集，需人工确认后改标为人工。一次最多处理 50 条。
- **导出数据集**：勾选「只导出已标注的样本」「同时复制音频文件」后导出。导出目录包含 `samples.jsonl`（每行同键，缺失写 null）、`samples.csv`（带 BOM，Excel 可直接打开）、`dataset-info.json`（版本 / 时间 / 条数）。

## 第 14 章 历史趋势

「历史趋势」页查询设备长期历史数据（软件在后台把实时数据自动落盘为列式文件并用内置引擎查询，用户只需选择条件查询即可）。

### 14.1 查询

1. 在**标题栏**的设备选择器中选择设备（页头同时显示机型徽标）。页面按机型自动切换形态：**声纹设备 = 多通道页**；**声学相机 / 空气声呐 / 推送设备 = 单线趋势页**（无通道概念，一张单线曲线图）。
2. 选择**指标**：声压级 / 主频 / 平稳度 / 频带能量比 / 奇偶谐波比 / 频谱复杂度 / 指纹变化度；**按住拖动可调整图表顺序**（点击切换显示 / 隐藏）。
3. 多通道页的右侧**通道列**：每行只显示**颜色点 + 通道名**，勾选显示 / 隐藏；无数据的通道灰显并禁止勾选；通道可重命名（写进设备，需设备在线且为声纹设备）；底部「全部显示」。
4. 选择**时间范围**（最近 1 小时 / 24 小时 / 7 天 / 30 天 / 自定义起止）与**颗粒度**（自动 / 1 秒 / 10 秒 / 1 分钟 / 5 分钟 / 1 小时 / 1 天；自动档按跨度挑桶宽并显示实际值），点击查询。
5. 每张图下方显示诊断行（点数 / 原始行数 / 聚合桶大小 / 扫描文件数 / 耗时）；结果超过最大点数上限时会提示缩小范围。图表下方还有「**时间段告警**」卡：列出**所选查询时间段内该设备的告警**（标注范围内条数），点击条目可前往处置。

### 14.2 缩放、导出与打印

- **缩放**：图上滚轮或底部范围条放大时间段，Y 轴随之弹性重算（声压级固定 0–100 dB 不变）；缩放后显示「当前显示第 a–b 个点（共 n 点）：时间范围」，「重置缩放」恢复全部图。
- **导出数据**：把当前屏幕查到的数据（仅正在显示的通道）存为 CSV，文件写入 `存储根目录/exports/trends/` 并显示行数与路径。
- **打印 / 存为 PDF**：打开打印对话框，目标选「另存为 PDF」即可获得 PDF（自动隐藏侧栏、顶栏与筛选控件）。

## 第 15 章 系统设置

「系统设置」分六个页签，修改后按块即时保存（个别块有明确的「保存」按钮）。**多数写入需要管理员账户**。

### 15.1 常规

四组设置同页排列：

- **语言**：English / 简体中文（zh-CN）/ 繁體中文（zh-TW）/ Español / Türkçe / Русский，切换后立即生效并记住选择；首次启动默认 English。
- **存储**：**存储路径**（录音 / 录像 / 抓图 / 趋势等数据的根目录，默认 `D:\HertzinnoData`，下分 `audio/ video/ snapshot/ detect/ metrics/ export/ logs/`；点击「浏览…」更换，更换后已有记录不失效，按相对路径寻址）；**保留策略**（录音保留天数、最小剩余空间（GB）——低于阈值自动暂停非必要录音并提示清理或调高阈值）；**磁盘占用**（已使用 / 总容量、剩余空间、本程序占用）。
- **视频与缓冲**：「打开软件时自动播放」开关；「同时直播路数上限」（视频墙并发路数）。
- **缓存**：设备探测与缓冲六参数——健康检查间隔（毫秒，≥1000）、离线判定失败次数（≥1）、请求超时（毫秒，≥1000）、告警前录制（秒）、告警后录制（秒）、环形缓冲区总时长（秒，且不小于告警前 + 告警后之和）；以及**趋势存储**状态（待写入缓冲、已写入文件 / 行数、最近落盘时间、最近错误）。

### 15.2 集成

三张卡：**SMTP 邮箱**、**地图**、**AI 服务**。

- **SMTP 邮箱**：SMTP 服务器、端口（默认 25；选 SSL 通常改 465）、连接安全（无 / SSL / STARTTLS）、要求认证（用户名 + 口令，口令保存在本机凭据库，可清除）、发件人地址、收件人（至少一个）。邮件内容由「告警」页签的模板决定；「发送测试邮件」验证配置。
- **地图**：
  - **地图来源（单选）**：**OpenStreetMap（默认）** / 预置服务（CARTO、天地图、Esri、MapTiler、Mapbox、TomTom、Stadia、OpenTopoMap 等，逐个标注授权边界）/ 自定义 API（XYZ 模板必须含 `{z}/{x}/{y}` 占位符、仅允许 `https://`，加密钥与署名；**切换预置会自动清空密钥输入框**，不同服务商的 Key 不通用、避免串用）/ **本地缓存地图**（使用本机已下载的瓦片缓存，需先在下方完成一次缓存下载）。
  - **瓦片缓存下载**：选择地图服务 → 设定级别范围（最小–最大级别）与区域经纬度（南 / 西 / 北 / 东，可「填入当前中心」）→「开始下载」；下载中显示进度（已处理 / 总数 / 失败数），结束后给出结果（下载 / 跳过 / 失败 / 总体积）。缓存保存在数据目录的 `map-cache/` 下；地图显示**缓存优先**——已下载的瓦片直接用，未命中再联网兜底。
- **AI 服务**：管理给异常声纹样本提候选标签的 AI 服务（均为 OpenAI 兼容的 `/chat/completions` 接口）。**选中哪条服务，样本库的 AI 标注就用哪条**；选中即启用（自动打开总开关）。
  - **厂家预置**：OpenAI（gpt-4o-mini）、DeepSeek（deepseek-chat）、Moonshot（moonshot-v1-8k）、智谱 GLM（glm-4-flash）、通义千问（qwen-plus）、Ollama 本地（`http://localhost:11434`，默认模型 qwen2.5:7b）、自定义。点预置只填**接口地址与模型**，密钥永远手填。
  - **服务列表**：单选「启用」某条；每行显示接口地址与密钥状态（已保存 / 未保存），**密钥本体永不回显**；密钥输入框留空 = 不改动已存密钥。
  - **添加 / 编辑 / 删除**：点「添加服务」或在列表中点「编辑」打开内联编辑器；「删除」需确认，**删除服务会一并删除其密钥**；最多保存 20 条。接口地址与模型明文保存在本机数据库；密钥按服务经 Windows 系统加密（safeStorage）单独保存，不写进日志。旧版本的单一 AI 配置升级后自动迁移为一条「默认服务」并被选中，原启用状态保留。

### 15.3 GIS 服务

把常用的瓦片服务**命名保存**起来（最多 20 条），随时一键切换：

- 点击「添加服务」→ 填写服务名称 → 可在编辑器中点预置自动填入 XYZ 模板与署名（密钥框随之清空）→ 填写密钥与署名 →「保存服务」；
- 列表中每条服务可「**应用**」（覆盖当前底图配置并自动打开开关）、「编辑」、「删除」（删除需确认）；
- 「**把当前配置保存为服务**」把上方表单的当前内容直接存为一条命名服务；
- 「**测试瓦片**」用表单当前值真实加载一张样例瓦片并回报成功 / 失败，便于排查无外网、密钥错误或服务器拒绝。

### 15.4 告警（告警联动 + 提示音）

**告警联动总开关在页签标题右侧**（显示 已启用 / 已关闭）；**告警联动默认关闭**。打开后，设备告警触发本机动作，五张动作小卡各自带内联开关与参数：

| 动作卡 | 说明 | 可调参数 |
|---|---|---|
| 录像 | 告警时录制一段本机 MP4 | 录像时长、冷却时间、正在录像时跳过 |
| 弹窗 | 屏幕弹窗提醒（不抢键盘） | 自动关闭秒数、冷却时间、同时最多几个 |
| 提示 | 顶栏铃铛的待处理告警列表（跨页面保留） | 保留条数（超出丢弃并提示） |
| 邮件 | 经 SMTP 发邮件（可附告警抓帧；服务器在「集成」页签配置） | 主题 / 正文模板、附带抓帧、冷却时间 |
| 频率上限 | 防止告警风暴的全局节流 | 全局次/分钟、冷却窗口秒数、窗口内 / 每接口上限 |

- **触发源**：轮询相机检测日志的间隔与最低告警等级；可选「检测反馈流加速器」。页面显示各源运行状态、最近轮询 / 错误、已触发次数。
- **测试**：按当前保存的服务器与模板发送测试邮件（先保存再测试；测试附件可选无 / 内置测试图片 / 相机当前画面）。
- **告警声音**：只绑定两个时机——「**告警联动弹窗提示音**」（联动动作弹出弹窗时播放）与「**设备推送告警提示音**」（设备推送的告警到达本机提示时播放）；各选一个声音（含自定义 WAV：添加、试听、改名、清除）。原按「越界侦测 / 区域入侵」等类型选音的方式已取消。

### 15.5 账号

- **当前会话**：当前账户、修改密码、退出登录。
- **账户管理**：新增账户（用户名 / 显示名称 / 角色 / 逐项权限）、编辑角色与权限、重置密码（对方首次登录需改密）、删除账户（不能删除当前登录账户与内置管理员；必须保留至少一个管理员）。
- 每项权限旁写明它管住的操作范围；可按已有账户「复制权限」或恢复默认权限（只读权限默认勾选，写入类权限需手工勾选）。

### 15.6 关于与维护

- 显示：应用版本、发布日期、构建日期、操作系统、数据库路径、存储根目录（路径带「复制」按钮）。
- **恢复默认值**：列出将恢复出厂的 16 项系统设置（存储路径、保留天数、探测与缓冲参数、自动播放、直播上限、告警联动、告警声音、在线底图、**GIS 服务库**等）逐项确认。恢复默认**不会**改动设备列表、通道、录像与录音文件、告警记录、账户与权限；磁盘上已有的文件也不会被删除。SMTP 口令保留在本机凭据库，如需清除请在邮箱设置中操作。

## 第 16 章 常见问题（FAQ）与故障排除

| 问题 | 排查步骤 |
|---|---|
| 设备显示「离线」 | ① 电脑能否 ping 通设备 IP（同一网段、网线/交换机正常）；② 设备电源是否正常；③ 添加设备时端口是否正确（HTTP 默认 80）；④ 设备已被其他软件占用连接数时稍后重试；⑤ 点击顶栏「刷新」重新探测。连续探测失败达到「离线判定失败次数」才判离线，刚断电的设备会延迟片刻。 |
| 「测试连接」提示认证失败 | 核对设备用户名/密码（设备出厂账户见随附资料；相机与声纹设备的设备账号是另一套体系，与本软件登录账户无关）。连续多次失败会触发设备自身的锁定策略，请稍后再试。 |
| 添加设备提示「设备无响应」 | IP / 端口 / 型号是否匹配；设备是否为受支持的四类设备；电脑防火墙是否放行本软件访问局域网（允许通过 Windows 防火墙）。 |
| 相机看不到视频（「相机 RTSP 未启用」） | 到相机 Web 界面（设备管理页双击该相机 IP）→「高级设置 → RTSP」启用后再试。 |
| 视频格提示「内置 ffmpeg 不可用」 | 安装包中的视频组件缺失，请重新安装本软件。 |
| 提示「已达同时直播上限」 | 先停止其他画面格或监测页的视频，或到「系统设置 → 常规（视频与缓冲）」调高「同时直播路数上限」（注意电脑性能与相机连接数限制）。 |
| 手动录像失败 | 界面会直接给出具体原因：「录像文件为空（0 字节）」多为磁盘空间不足或相机码流中断，请清理磁盘后重试；「录像文件不完整（缺少 moov 索引）」说明视频流在录制过程中中断，请重新开始录像。 |
| 复制 RTSP 地址失败 | 软件已内置剪贴板写入权限，正常可直接复制；若系统提示剪贴板被占用，稍候重试一次。 |
| 推送设备一直显示离线 | 推送设备没有 IP 轮询，**收到设备推送的遥测才上线**，超过阈值时间无遥测即判离线。请检查：设备侧推送地址 / 端口 / 秘钥是否与本机一致（添加设备 → 本机接入里查看监听地址与收数统计）；本机防火墙是否放行监听端口；秘钥轮换后设备是否仍用旧秘钥（旧秘钥立即失效）。 |
| 检测模式下各通道曲线对不齐 | 这是数据口径而非故障：设备一次只开一路流，每条曲线是该通道本次订阅期间收到的读数——通道内连续、跨通道时间不同步，横轴不能直接互相比对。 |
| 录像/录音播放失败 | 本机文件是否已被清理或移动（存储路径是否被更换）；未下载的设备侧录音需先从设备下载；相机回放只支持本机文件（FA371 无设备侧连续录像）。 |
| 告警触发但没有任何联动动作 | 「系统设置 → 告警」确认「启用告警联动」与各动作开关已打开；检查冷却时间与频率上限是否把动作跳过（联动面板显示每次动作的状态与原因）；相机联动还需设备上已启用告警策略。 |
| 邮件发不出 | 「系统设置 → 集成（SMTP 邮箱）」核对 SMTP 服务器 / 端口（SSL 用 465）/ 认证 / 发件人；先「保存」再「发送测试邮件」，错误原文会显示在界面上；确认发件账户允许 SMTP 客户端发送。 |
| 忘记软件登录密码 | 见 4.4：登录页「忘记密码？」→ 复制安装标识 → 联系厂家签发超级密码 → 重置。忘记设备密码请联系设备厂家。 |
| 登录提示失败次数过多 | 同一账户连续 5 次失败后锁定 60 秒，请稍候再试或找回密码。 |
| 磁盘空间不足 | 「系统设置 → 常规（存储）」查看磁盘占用与剩余空间；减小录音保留天数、调高最小剩余空间阈值，或更换存储路径到大容量磁盘。低于阈值时软件会自动暂停非必要录音。 |
| 换了电脑 / 重装系统数据还在吗 | 设备列表、告警、样本等存在本机数据库（路径见「系统设置 → 关于与维护」）；录音录像在存储根目录。迁移时请一并备份数据库文件与存储目录。 |
| 界面想换语言 | 「系统设置 → 常规（语言）」切换，立即生效并记住。 |
| 地图离线缓存怎么用 | 「系统设置 → 集成（地图）」：先在「瓦片缓存下载」选地图服务、级别范围与区域经纬度（可「填入当前中心」）→「开始下载」，下载进度与结果（下载 / 跳过 / 失败）实时显示；缓存存于数据目录 `map-cache/`。之后把「地图来源」切到「本地缓存地图」，地图即优先用缓存、未命中再联网。 |
| 提示音绑定后何时响 | 告警声音只绑定两个时机：「告警联动弹窗提示音」在告警联动的**弹窗动作**弹出时播放；「设备推送告警提示音」在**设备推送的告警**到达本机提示时播放。若告警联动总开关未打开、或对应动作未启用，不会响。 |
| 地图上没有我的设备 | 该设备未录入经纬度点位：设备管理 → 编辑设备（设置列）填写地址信息（经纬度成对录入）。 |
| 在线底图不出图 | 「系统设置 → 集成（地图）」确认已启用且模板为 https；检查本机能否访问所选瓦片服务（代理/证书/限流）；可在「GIS 服务」页签的编辑器里点「测试瓦片」直接验证地址与密钥；失败提示不影响设备点位。 |
| 事件中心某一条无法确认 | 相机检测日志在设备侧没有确认接口，本机不能替设备确认；可在本机 Incident 中记录处置。 |
| SmartScreen 拦截安装 | 点击「更多信息 → 仍要运行」（安装包未做代码签名）。 |

**日志与诊断**

- 软件日志经 electron-log 写入用户数据目录下的 `logs/`（Windows 一般为 `%APPDATA%\hertzinno-acoustic-box-manager\logs`），分应用（`app-*.log`）、设备通信（`device-*.log`）、存储（`storage-*.log`）三类，密钥与口令不会写入日志。联系厂家支持时，请连同日志与「系统设置 → 关于与维护」中的版本信息一并提供。
- 「协议实验室」页提供只读协议诊断（端点探测、认证方式识别、原始响应样本）。该页面向诊断设计，**请在厂家支持指导下使用**；诊断全程只读，不会修改设备配置。

| 弱标签 / AI 候选标签 | 设备判定（弱）与 AI 建议（候选）两类标签，可信度低于人工标注，不直接进入训练集 |
| 留一法 | 训练评估方法：每次留一个样本做验证、其余训练，逐个轮换 |
| MQTT | 轻量物联网消息协议，设备经主题向本机推送遥测 |
| RS485 / Modbus | 工业串行通信接口与常用工业通信协议，用于设备接入现场总线 |
| NTP | 网络对时协议，用于校准设备时钟 |
| Push 上报 | 设备主动向指定地址（HTTP/MQTT）周期推送特征、告警、图形、热力数据 |
| 环形缓冲区 | 实时音频在内存中的循环缓存，用于告警前预录与手动录音截取 |
