# HAIS v1.0.49 Release

## Highlights

- Restored current alarms, alarm history and device list below the GIS map.
- Device points accept manual latitude/longitude input.
- SPL trends for acoustic cameras and 16-channel Air Sonar.
- Alarm time, direction, type, snapshot and recording stay in sync.
- Video-wall configuration persists and auto-restores online cameras.
- Playback timeline defaults to one hour; volume slider is vertical.
- 1-degree directional sector for 16-channel Air Sonar.
