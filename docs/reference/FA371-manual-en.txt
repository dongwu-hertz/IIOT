System Introduction
Summarize
An acoustic camera, also known as an acoustic imager, is a device that converts a sound field into a visual image. Acoustic imaging (acoustic imaging) is based on the microphone array measurement technology, through the measurement of a certain space within the sound wave arrives at the microphone signal phase difference, based on the phased array principle to determine the location of the sound source, measure the amplitude of the sound source, and display the distribution of the sound source in the space in the form of an image, i.e., to obtain the spatial distribution of the acoustic field cloud - acoustic image, where the color and brightness represent the strength and weakness. The color and brightness of the image represent the intensity. The device has sound acquisition, image acquisition, sound positioning visualization functions, to achieve visual detection of equipment failure clinic, the device is small in size and light in weight, can be mounted on all types of inspection robots, for the robot inspection method to further empower.
This system adopts the international leading ESR environmental sound target recognition technology, sound source positioning technology based on beam formation theory, measuring the location of the sound emitted by the equipment and the state of sound radiation, from the audible sound band to the ultrasonic frequency band full coverage of the collected sound to the visualization of the color contour mapping way. Effective measurement of the sound field distribution, the sound field map and the video image of the visible light perfectly superimposed, forming a similar thermal imaging instrument for the detection of object temperature. The device not only has the functions of traditional acoustic camera sound acquisition, image acquisition and visualization of sound positioning, but also can detect and locate the abnormal position in real time when the equipment fails.
This equipment can be used in a variety of industrial scenarios, such as: partial discharge monitoring function of high-voltage transmission lines, high-voltage pipeline gas leakage monitoring function, partial discharge fault monitoring function of transformers, switchgear and other equipment. This system can be used for sound source localization, abnormal sound detection, sound source location tracking and positioning. For steady state or high transient sound sources, static or moving objects can be obtained excellent detection results.

 Alarm Setting
On this page, users can customize the alert policy according to their needs, and the custom alert policy contains the following:
Strategy Name: Strategy Name
Alarm conditions: including decibel alarm, main frequency alarm, spectrum comparison, users can flexibly select and set these alarm conditions according to the actual needs to ensure that the alarm can be accurately triggered in specific situations.
Detection cycle: the length of time for a single detection can be set from 1 to 30 seconds. Users can adjust the length of the detection cycle to balance the detection accuracy according to the actual demand.
Sensitivity: This parameter measures the rate at which the detection threshold is exceeded in a single detection. The higher the sensitivity, the more sensitive the system's response to abnormal signals, but it may also lead to an increase in the false alarm rate. Therefore, users need to set the sensitivity parameter reasonably according to the actual situation.
Alert Level: This field is used to mark the urgency or importance level of the policy. By setting different alert levels, users can prioritize different types of alerts to ensure that urgent and important alerts are prioritized when resources are limited.
Diagnostic Description: This field provides a way for the user to record a description of the policy definition. Users can enter a detailed description of the background, purpose, applicable scenarios, and other information about the strategy's development for subsequent review and understanding. By completing the diagnostic description, the user can better communicate the intent of the strategy's development and make it easier for other users to understand and apply the strategy.

 Statistical mapping
In order to comprehensively understand and analyze the acoustic characteristics of each sound field point during a historical day, we need to provide detailed statistics and visualization of the sound pressure information as well as the dominant frequency information at a specific moment in time.
Sound pressure information statistics:
For each sound field point during a historical day, its sound pressure level is accurately measured and recorded at specified moments. This data will help us to understand the distribution of sound intensity at each site over time and assess whether it meets the relevant noise standards or has potential acoustic problems.
Master frequency information statistics:
In addition to the sound pressure information, we will also count the main frequency information of each sound field point at the specified moment. The dominant frequency is the frequency component with the highest energy in the sound signal, which is important for determining the source, nature and possible acoustic impact of the sound signal. Through the statistics of the main frequency information, we can further analyze the sound characteristics of each sound field point, such as whether there is a specific noise source or vibration source.

Function Description: Used to set the parameter values of MIC matrix sampling rate (unit KHz), upper limit of analyzing frequency band (unit KHz), lower limit of analyzing frequency band (unit KHz), and so on.

Websocket interface
In order to ensure real-time data transmission, device parameters are obtained using Websocket protocol on port 80. device parameters are obtained according to a customized communication protocol after the connection is established.
Request Format ws://localhost:port
Heartbeat mode is set to ensure a correct and secure websocket connection. After connecting to the device's websocket server, all clients in normal use are required to send arbitrary messages (with unlimited content) to the server every minute to ensure that the connection is not interrupted. Otherwise, the server will determine that the client is not in use and forcibly interrupt the connection.
Get fft data
Request address ws://localhost:port/fftData
The device will return the FFT data on average five times per second (the first half of the FFT, the length of 512), the return form of 16-bit int-type binary stream, the returned data can be parsed in byte order.
Getting a voiceprint image
Request address ws://localhost:port/voiceprintData
The device will return one frame of voiceprint image data per second on average, the return form is int-type binary stream, the returned data can be parsed in byte order.
Access to test results
Request address ws://localhost:port/detectFeedback

Getting Heterophonic Points Information
Request address ws://localhost:port/energyData
The device will regularly return heterodyne point energy value data in the form of a 32-bit int-type binary stream, and the returned data can be parsed in byte order.
Transmit several groups of target point information according to the number of targets set at present, the target point information is arranged in order, if the number of targets is 3, the information is arranged as follows: [ [target 1 information], [target 2 information], [target 3 information]], and the data in each group of information is arranged as follows: [energy, pixel transverse coordinate, pixel longitudinal coordinate, swath angle, azimuth angle].
Get real-time audio data
Request address ws://localhost:port/pcmData
The device will return PCM data every second, at a sampling rate of 48 KHz (48000), in the form of a float32-type binary stream.
Just parse the returned data in byte order.
