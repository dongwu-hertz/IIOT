1.1 Required Materials
No.
Item
Description

1.2 Precautions
⚠️ Do not power off the device during the upgrade. Ensure a stable power supply.
⚠️ It is recommended to back up the current system configuration before upgrading so that it can be restored if necessary.
⚠️ Do not perform other operations during the upgrade. Wait until the entire upgrade process is complete.
After the upgrade, restart the device and verify that all functions operate normally.

After the upload is complete, add execute permission to the upgrade package.
Log in to the device command line through the backend terminal or SSH.
Change to the directory containing the upgrade package (adjust the path according to the actual upload location):
 cd /root/
Make the upgrade package executable:
chmod 755 FE128_ROBOT_PLUS_upgrade_pkg_RK3568_v2.0.11
Verify that the permissions were changed successfully:
ls -l FE128_ROBOT_PLUS_upgrade_pkg_RK3568_v2.0.11
Confirm that the permission field in the output is -rwxr-xr-x, indicating that the permission change was successful.
