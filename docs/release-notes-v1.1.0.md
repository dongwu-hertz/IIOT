# HAIS v1.1.0 Release

发布日期 / Release date: 2026-11-24

## Highlights

- 16-channel Air Sonar map keeps the real 1-degree sector, with a visible direction ray, arrowhead and 100 m range label.
- Air Sonar detail map supports mouse-wheel zoom and left-button drag pan; tiles, marker and sector move together.
- Camera detail no longer probes non-existent FA8 configuration endpoints, removing the false `AUTH_FAILED` banner.
- Camera detection-log parse failures no longer increment the offline-failure counter.
- Event-center detail drawer header wraps action buttons below the title on narrow widths, fixing compressed/wrapped device text.
